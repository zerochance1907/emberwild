# Credits

Emberwild uses **no third-party art, audio or font files**.

- **Art:** all creature sprites, characters, tiles, UI and effects are generated from code in `src/art/` at startup. They are original to this project.
- **Music and sound:** composed for this project and synthesized at runtime with the Web Audio API (`src/audio/`).
- **Fonts:** the game uses the player's system fonts (Trebuchet MS, Segoe UI, Helvetica or Arial), so no font files are bundled.
